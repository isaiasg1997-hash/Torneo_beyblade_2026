
Proyecto: Super Final Beyblade Avanzado
Archivos en este ZIP:
- index.html
- style.css
- script.js
- assets/img/ (agrega tus imágenes de fondo aquí, por ejemplo 'fondo-torneo.png')

Instrucciones:
1. Extrae el ZIP en una carpeta.
2. Abre index.html en un navegador moderno.
3. Ingresa los jugadores en los formularios A y B (16 cada uno).
4. Haz clic en 'Crear Torneos' y avanza haciendo click en los jugadores.
5. Usa los botones Exportar para PNG, JSON y PDF.
